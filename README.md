# AI CV Screener — n8n Automation

An AI-powered workflow built with n8n to help automate the initial screening of candidate CVs against a job description.

## Features

- Automated CV screening using AI
- Candidate evaluation against job requirements
- Structured screening results to support recruitment
- Reduced manual effort during initial candidate review

## How It Works

1. **Input:** Provide candidate CV information and a job description.
2. **Processing:** Extract and process the relevant CV content.
3. **AI Evaluation:** Evaluate the candidate's qualifications against the job requirements.
4. **Output:** Generate screening results for human review.

*Adjust these steps to match the actual implementation of your workflow.*

## Technology Stack

- n8n workflow automation
- AI model/API used by the workflow
- Document processing and structured output

## Setup

1. Import the exported workflow JSON into your n8n instance.
2. Configure the required credentials and integrations.
3. Review the workflow nodes and update any required settings.
4. Test with sample CVs and job descriptions.

## Privacy and Responsible Use

- Never upload real candidate CVs or personal information to this public repository.
- Configure credentials securely in n8n.
- AI-generated evaluations may be inaccurate or biased.
- Use screening results as decision support, with human review before recruitment decisions.
